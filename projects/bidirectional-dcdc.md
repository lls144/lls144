# Bidirectional DC/DC

这份笔记从控制与采样电路看双向同步 Boost。

## 让功率级看得见自己

个人负责控制电路与采样电路设计。方案以 STM32G474 为主控，把电压／电流反馈接入 PI 控制；其背景是高校电气电子工程创新大赛的施耐德电气 Go Green 电力电子创赢赛道。

首页分压器是“物理电压进入 ADC 量程”的通用局部示意，没有给出本项目实装阻值，也不替代实际模拟前端。

## 初设停在哪一步

现有初设报告确认了拓扑选择和电路仿真，当时仍处于元件选型、PCB 与程序推进阶段。报告还讨论并联均流和 ZVS / ZCS 软开关研究，这些内容属于团队方案，不直接等同于个人完成了全部实现。

| 报告中的设定 | 当前口径 |
| --- | --- |
| 75–240 V / 400 V | 方案端口电压范围 |
| 500 W / 模块 | 设计目标 |
| 200 kHz | 初设频率取值 |
| 95% 效率 | 设计目标 |
